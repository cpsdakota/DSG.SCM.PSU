1. Prerequisites

Working Directory

All commands must be run from the project root. Navigate there first:

cd /Users/pmaidana/Documents/pedro_test/pso-ansible-dicksportinggoods-1445726

Virtual Environment

Activate the Python virtual environment before running any playbook:

source .venv/bin/activate
# Prompt will show (.venv) when active

Vault Password File

Most playbooks load encrypted credentials. The vault password file .vault_pass must be present in the project root and passed to every command:

--vault-password-file .vault_pass
Important: Never commit .vault_pass to git. It is already listed in .gitignore.

3. Playbooks Overview

firewalls_backups.yml firewalls group

Connects to every firewall in the [firewalls] inventory group, exports the running and merged running configuration (YAML + XML), and runs a set of operational commands (show system info, show system disk-space). Saves all output locally.

  • firewalls_backups/running-config-<hostname>.yaml
  • firewalls_backups/running-config-<hostname>.xml
  • firewalls_backups/merged-running-config-<hostname>.yaml
  • firewalls_backups/merged-running-config-<hostname>.xml
  • command_outputs/command-output-<hostname>.txt

list_devices.yml SCM API

Queries the SCM internal API to list all devices registered in Strata Cloud Manager. Runs on localhost (no SSH to devices) — displays serial, hostname, model, connectivity status, software version, and uptime. Does not support --limit filtering (it is an API query, not a per-device playbook).

pre_snapshot.yml firewalls group

Takes a pre-change state snapshot of each firewall before making configuration changes. Uses the take_snapshot role. Run this before any change window.

  • snapshots/pre_snapshot_<hostname>.json

4. firewalls_backups.yml — Execution Examples

▶ All firewalls in inventory

Runs against both dicks-vmseries-lab2-firewall01 and dicks-vmseries-lab2-firewall02.

ansible-playbook playbooks/firewalls_backups.yml \
    --vault-password-file .vault_pass
▶ One specific firewall — using --limit

The --limit (or -l) flag restricts Ansible to a single host from the inventory.

ansible-playbook playbooks/firewalls_backups.yml \
    --vault-password-file .vault_pass \
    --limit dicks-vmseries-lab2-firewall01

Alternative — using the built-in firewall_list variable:

ansible-playbook playbooks/firewalls_backups.yml \
    --vault-password-file .vault_pass \
    -e 'firewall_list=["dicks-vmseries-lab2-firewall01"]'
▶ Multiple specific firewalls

Comma-separate hostnames in --limit, or pass a list to firewall_list.

# Using --limit (comma-separated, no spaces)
ansible-playbook playbooks/firewalls_backups.yml \
    --vault-password-file .vault_pass \
    --limit dicks-vmseries-lab2-firewall01,dicks-vmseries-lab2-firewall02
# Using the firewall_list variable
ansible-playbook playbooks/firewalls_backups.yml \
    --vault-password-file .vault_pass \
    -e 'firewall_list=["dicks-vmseries-lab2-firewall01","dicks-vmseries-lab2-firewall02"]'

5. list_devices.yml — Execution Examples

Note: This playbook runs on localhost and queries the SCM API — it is not targeted at individual firewalls. --limit has no effect. It always returns all devices registered in SCM.
▶ List all SCM-registered devices 
ansible-playbook playbooks/list_devices.yml \
    --vault-password-file .vault_pass

Output includes: Serial, Hostname, Model, Connected status, Software Version, Uptime.

6. pre_snapshot.yml — Execution Examples

Important: Run this playbook before making any changes to the firewalls. It captures the current device state for later comparison (e.g., with a post-change snapshot).
▶ All firewalls in inventory

Snapshots both firewalls and saves results to ./snapshots/.

ansible-playbook playbooks/pre_snapshot.yml \
    --vault-password-file .vault_pass
▶ One specific firewall 
ansible-playbook playbooks/pre_snapshot.yml \
    --vault-password-file .vault_pass \
    --limit dicks-vmseries-lab2-firewall01

Saves: snapshots/pre_snapshot_dicks-vmseries-lab2-firewall01.json

▶ Multiple specific firewalls 
ansible-playbook playbooks/pre_snapshot.yml \
    --vault-password-file .vault_pass \
    --limit dicks-vmseries-lab2-firewall01,dicks-vmseries-lab2-firewall02

7. Quick Reference

Playbook Targets Supports --limit Supports firewall_list Vault Required
firewalls_backups.yml firewalls Yes Yes (built-in) Yes
list_devices.yml localhost (SCM API) No No Yes
pre_snapshot.yml firewalls Yes No Yes
--limit vs firewall_list: Both achieve similar results for firewalls_backups.yml. --limit is the standard Ansible approach and works for all playbooks. firewall_list is a custom variable built into firewalls_backups.yml only.
